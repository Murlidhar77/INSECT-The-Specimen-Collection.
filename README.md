# Insect Specimen Landing Page

A modern landing page concept for an insect collection, featuring a specimen showcase, scientific classification, and collection options. Built with HTML and CSS, with a focus on layout, typography, and visual design.

## Features

- Split-screen layout with contrasting background colors
- Navigation bar with a search field
- Scientific classification details
- Specimen showcase with pricing
- Collection button and interactive-style options

## Built With

- HTML5
- CSS3
- CSS Grid and Flexbox

## Getting Started

1. Clone this repository:
   ```bash
   git clone https://github.com/Murlidhar77/insect-specimen-landing-page.git
   ```
2. Open the project folder.
3. Open `index.html` in your browser.

## What I Practiced

This project helped me practice CSS Grid, Flexbox, positioning, and creating a structured landing page with a distinct visual style.
